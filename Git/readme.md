# L'UTILITE DE GIT

 *  install git
       
       
        https://git-scm.com/

 * Initiate a folder to use git control    version
       
        git init  

 * State of tracking file
       
       git status 

 * git add .
       
        save all changes files

 * Commit changes
        
        git commit -m "commited message"

 *   Send all changes on SVC(Github, Gitlab, Bickbucket)
       
        git push

 *  Get changes made in files

         git diff codeSHA

 *  Offset on a git commit specific version
       
        git reset --hard idSha

 *  Display history of commit
      
        git log

* Get all branches
   
        git branch
